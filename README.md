# Java Hotel Management System

Console based hotel management system developed
in Java as part of university group assignments.

## Features
- Add new hotels
- View hotel information
- Edit hotel information
- Remove hotels
- Search hotels
- View operation logs

## Technologies
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Exception Handling

## OOP Concepts
- Inheritance
- Encapsulation
- Abstraction
- Polymorphism

## How to Run
1. Compile the Java files.
2. Run TestProgram.java.
3. Follow the menu instructions.
